# 全国大会標準チェッカー 2026

タイムを入力すると、**日本水泳連盟の2026年 全国大会 標準記録**を突破しているか（突破／あと◯秒）をまとめて確認できるWebアプリです。

- 単一の `index.html` だけで動作（外部CSS/JS/画像・通信なし）。オフラインでもスマホでもそのまま開けます。
- スマホ最優先レイアウト（375px / 320px で横はみ出しゼロを確認済み）。

## 使い方

1. `index.html` をブラウザで開く（またはダブルクリック）。
2. **男女 / 水路（長水路・短水路）/ 年齢 / 種目 / 距離** を選び、**タイム**を入力（例：`52.19` または `1:02.34`）。
3. 各大会の標準に対して「突破」または「あと◯秒」がカードで一覧表示されます。
4. **大会カテゴリ**チップで絞り込み、**突破だけ表示**でクリア済みのみ表示できます。

| 大会 | カテゴリ | 水路 | 区分 |
|---|---|---|---|
| 日本選手権2026 | 日本選手権・JO | 長水路・短水路 | — |
| ジャパンオープン2026 | 日本選手権・JO | 長水路・短水路 | — |
| 日本学生選手権2026 | 大学 | 長水路・短水路 | — |

| インターハイ2026 | 高校 | 長水路のみ | — |
| 全国中学2026 | 小中・JOC | 長水路のみ | — |
| JOC夏季2026 | 小中・JOC | 長水路・短水路 | 年齢別（9歳以下〜15-16歳）＋CS |
| 国スポ2026 | 国スポ | 長水路のみ | 少年B／少年A／成年 |

### 仕様メモ

- **年齢を入れるとJOCの年齢区分を自動判定**します（該当年齢区分＋CSを表示。17歳以上はCSのみ）。
- **国スポの区分（少年B／少年A／成年）** は「国スポ区分」プルダウンで選びます（「すべて」で全区分表示）。
- **インターハイ・全国中学・国スポは長水路のみ** 収録のため、短水路を選ぶとこれらの大会は結果に出ません（「なし」とは表示しない設計）。
- 判定は 1/100 秒まで。**入力タイム ≦ 標準記録** で「突破」。長水路・短水路は選択した水路で判定します。

## 公開方法（GitHub Pages / Cloudflare Pages）

このフォルダは `index.html` がルートにある静的サイトなので、そのまま公開できます。

**GitHub Pages**
1. このフォルダをGitHubリポジトリにアップロード（`index.html` はリポジトリの直下に置く）。
2. リポジトリの Settings → Pages → Source を `main` ブランチ / `/ (root)` に設定。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

**Cloudflare Pages**
1. Cloudflare Pages で新規プロジェクトを作成し、このリポジトリを接続（またはフォルダを直接アップロード）。
2. ビルド設定は不要（フレームワークなし／ビルドコマンド空欄／出力ディレクトリはルート）。
3. デプロイ後、割り当てられた `*.pages.dev` のURLで公開されます。

> ビルド工程は不要です。`index.html` を1枚置くだけで動きます。

## 毎年の更新

標準記録は毎年変わります。更新する場合は `index.html` 内の `const ENTRIES = [ ... ]`（種目ごとの標準タイム）を差し替えてください。1件は次の形です。

```js
{ "meetName":"日本選手権2026", "group":"open", "gender":"male",
  "stroke":"fr", "distance":100, "event":"fr100", "course":"lc",
  "standard":"49.96", "division":"", "ageMode":"" }
```

- `stroke`：`fr`(自由形) / `ba`(背泳ぎ) / `br`(平泳ぎ) / `fly`(バタフライ) / `im`(個人メドレー)
- `course`：`lc`(長水路) / `sc`(短水路)
- `division`／`ageMode`：JOC＝`ageMode:"joc"` と年齢区分（`9under`〜`15_16`,`cs`）、国スポ＝`ageMode:"kokuspo"` と `少年B`/`少年A`/`成年`。それ以外は空文字。
